## 📁 Repository Structure

Each assignment folder includes its own `README.md` with the aim and task details. Depending on the assignment, it may also contain:

* `source-code.js` — JavaScript code for the tasks
* `browser-source.html` — HTML/CSS source for browser-based exercises
* `output.txt` — Expected output and run notes

```text
JavaScript-Programming-Lab-BCS354/
├── Assignment-01/

│   ├── source-code.js

```

## 🚀 How to Run

### 1. JavaScript using Node.js
1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open a terminal or command prompt in the assignment folder.
3. Copy the required task section into a JavaScript file if the source contains multiple tasks.
4. Run it using the following command:
   ```bash
   node filename.js
   ```

### 2. Browser-based Tasks (HTML / CSS / JS)
1. Copy a complete HTML task into a `.html` file (or open the existing `browser-source.html`).
2. Save the file.
3. Open it directly in any web browser and follow the task instructions.
